# LED 状态映射表（WS2818 RGB @ GPIO48）

> 由 `stats.cpp` 的 `stats_update_led()` 实现，驱动用 Adafruit NeoPixel（WS2818 协议兼容 WS2812）。

## 编码原则

- **颜色 = 身份（角色）**：一眼看出这台机器是谁
- **节奏 = 健康（链路）**：一眼看出它现在健不健康
- **硬件故障（射频/看门狗）= 整灯红**，覆盖角色色（故障最高优先级）

## 角色色

| 角色 | 颜色 | RGB（NeoPixel setPixelColor 用 R,G,B） |
|---|---|---|
| GCS（地面站） | 绿 | (0, 255, 0) |
| AIR（机载） | 蓝 | (0, 0, 255) |
| RELAY（中继） | 青 | (0, 255, 255) |
| 未配置 / 配置中 | 橙 | (255, 128, 0) |

## 健康节奏

> ⚠️ **现状（2026-10-17 上板核对）**：`stats_update_led()` 只设置**颜色**，**节奏（闪烁）尚未实现** —— 下表"节奏"列是设计目标；当前所有状态都是**常亮**。
> 上板实测（未接射频模块）：`radio_is_ready()==false` → health=FAULT → **红灯常亮**，与设计语义一致。

| 健康 | 节奏 | 周期 |
|---|---|---|
| 正常 | 常亮 | — |
| 待机（无邻居） | 慢闪 | 1 次/秒 |
| 丢链（failsafe 触发） | 快闪 | 5 次/秒（200ms） |
| 配置模式 | 双闪 | 闪 2 下停 1 下 |
| 射频故障（自救中） | 红快闪 | 200ms |
| 看门狗复位（刚重启） | 红闪 1 下 | 单次 |

## 完整状态表

| 状态 | 颜色 | 节奏 |
|---|---|---|
| 上电启动 | 白 (255,255,255) | 快闪 3 下 |
| 未配置 | 橙 | 常亮 |
| 配置模式 | 橙 | 双闪 |
| GCS 正常 | 绿 | 常亮 |
| GCS 待机 | 绿 | 慢闪 |
| GCS 丢链 | 绿 | 快闪 |
| AIR 正常 | 蓝 | 常亮 |
| AIR 待机 | 蓝 | 慢闪 |
| AIR 丢链 | 蓝 | 快闪 |
| RELAY 正常 | 青 | 常亮 |
| RELAY 待机 | 青 | 慢闪 |
| 射频故障 | 红 (255,0,0) | 快闪 |
| 看门狗复位 | 红 (255,0,0) | 闪 1 下 |

## 实现要点

1. 驱动：`Adafruit_NeoPixel strip(1, PIN_LED, NEO_GRB + NEO_KHZ800)`（单颗灯）
2. 更新：`stats_task` 每 1s 刷新一次
3. 去抖：状态切换至少保持 500ms，避免外场看灯"乱抖"
4. 优先级：**故障 > 丢链 > 待机 > 正常**（丢链/待机保留角色色，只有故障才整灯红）
5. 非阻塞：用 `millis()` 判闪烁相位，绝不在 LED 上 `delay()`
